# Fourmi

`fourmi` is an OCaml library that offers *speculative parallel execution*
of user-defined tasks on a single hardware thread.

## Installation and Usage

Type `opam install fourmi`.

In your `dune` file, add `(libraries fourmi)` to the description of
your `library` or `executable`.

## Documentation

For more information,
please see the [documentation of the latest released
version](http://cambium.inria.fr/~fpottier/fourmi/doc/fourmi/).
